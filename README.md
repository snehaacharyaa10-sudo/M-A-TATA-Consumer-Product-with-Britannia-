Tata Consumer × Britannia — M&A Accretion / Dilution Model
Overview

This project is an ongoing hypothetical M&A accretion/dilution model evaluating a potential acquisition of Britannia Industries by Tata Consumer Products.

The model assesses the transaction from the perspective of the acquirer by calculating the purchase consideration, financing mix, incremental financing costs, transaction synergies, pro forma earnings and the resulting EPS accretion/dilution.

The model is structured as a simplified investment banking-style transaction model and is intended as a financial modeling / proof-of-work project, not as an indication of an actual proposed transaction.
Disclaimer

This is an academic / financial modeling project based on a hypothetical transaction.

The transaction assumptions, financing structure, synergies, interest rate and other modeling inputs are assumptions used for analytical purposes. The model does not represent an actual offer, transaction proposal, valuation opinion or investment recommendation.

Project Objective

The objective of this project was to build a compact, interconnected M&A model that demonstrates how an acquisition can affect an acquirer's earnings per share under different purchase price and financing assumptions.

Rather than focusing only on valuation, the model connects transaction structure → financing → transaction adjustments → pro forma earnings → EPS accretion/dilution.
